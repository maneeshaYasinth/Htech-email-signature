Add it to Zoho Mail

  1. Click Copy signature above.
  2. In Zoho Mail, open Settings and choose Signature.
  3. Add a new signature and paste with Ctrl+V (Cmd+V on a Mac).
  4. Save it and set it as the default for your htechcore.com address.

Using Gmail? Go to Settings, then See all settings, then General, and paste into Signature. Click Save changes at the bottom of the page.
